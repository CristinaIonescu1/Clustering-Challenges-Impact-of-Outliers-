# Clustering-Challenges-Impact-of-Outliers-
Unsupervised learning study comparing K-Means, DBSCAN, and GMM. Evaluates algorithm resilience to outliers and non-spherical data distributions using Silhouette and ARI metrics.  
This project investigates unsupervised segmentation of wine chemical data by comparing K-Means, DBSCAN, and Gaussian Mixture Models (GMM). A critical part of the workflow involved refining the dataset from 1,599 to 1,359 records by removing duplicates and applying StandardScaler to normalize the 11 explanatory variables.
A key strategic decision was the deliberate retention of outliers to evaluate model resilience and robustness under noisy conditions. The results highlighted the varying sensitivities of the algorithms: while K-Means was skewed by extreme values and DBSCAN failed to identify distinct density regions, GMM emerged as the most resilient model, achieving the only positive ARI score (0.034). This probabilistic approach proved superior in handling the significant overlap between quality classes. The project demonstrates that without dimensionality reduction, wine quality attributes remain heavily intertwined, ultimately concluding that this dataset is better suited for supervised learning tasks.
